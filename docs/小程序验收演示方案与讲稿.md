### S3 创建项目（约 45 秒）

首页"+" → `/pages/create/create`。四步：`基础信息` `阶段` `分工` `规则`（[create.vue:295-300](file:///d:/zxc/work/git/roc-git/repository/roc-git/src/pages/create/create.vue#L295-L300)）。

1. **基础信息**：项目名称*、所属小组（picker，默认第一个）、项目描述；`下一步` 校验名称与小组。
2. **阶段**：默认 4 行（需求分析/方案设计/编码实现/测试验收）；`快速模板：课程项目 / 调研报告 / 敏捷迭代` 会整体替换阶段；每行可改名称、选结束日期、×删除；`+ 添加阶段`。
3. **分工**：`项目成员` 头像 chip 可多选；`任务分工` 有 `快速添加：通用开发 / 报告答辩`；任务行可填名称、所属阶段、截止日期、描述。
4. **规则**：`挂单审核`、`截止提醒` 两个开关（默认开）；下方`项目概览`汇总。
5. 点 `创建项目`：先创建项目，再逐条创建任务，**任务负责人固定为当前登录用户**（代码里就是"简化：默认当前用户"，[create.vue:600-620](file:///d:/zxc/work/git/roc-git/repository/roc-git/src/pages/create/create.vue#L600-L620)）；toast `创建成功` 后 800ms 跳项目详情（[create.vue:629-637](file:///d:/zxc/work/git/roc-git/repository/roc-git/src/pages/create/create.vue#L629-L637)）。

## 三、视频讲稿（按上面的真实路径，约 6 分钟）

> 括号内是画面操作提示，不需要念出来。

### 片头（0:00–0:15）
> "大家好，这是 ROC-git 课程项目协作平台的微信小程序端。下面从登录开始，完整走一遍小组协作、文件审核、阶段任务和消息的日常使用流程。"

### 登录（0:15–0:45）
（先直接点"微信一键登录"，出现提示；再点输入框带出昵称，再登录）
> "未登录时不能进入。昵称为空直接点登录，只会提示请先填写昵称。点这个输入框，微信会一键带出我的真实昵称。点击'微信一键登录'，登录成功进入首页。"

（依次点三个统计卡）
> "首页顶部是当前小组，可以下拉切换。下面是三块统计：进行中、待审核、临期。点'进行中'，页面平滑滚动到当前项目；点'待审核'，定位到待审核文件；点'临期'，定位到七天内到期的任务。项目卡上能看到当前阶段、完成进度和成员。"

> "点小组名进入管理面板。组长可以展开成员、重命名小组、生成邀请码；邀请码复制后发给同学，对方在下方输入邀请码就能加入。"

## 四、录制红线：这些控件在演示里不要点，或点了要绕开

| 控件 | 实际行为 | 建议 |
|---|---|---|
| 首页待审核区的`通过` | 只 toast，不落库（home.vue:393-397） | 审核统一到项目详情文件 Tab 演示 |
| 首页待审核区`全部` | 跳第一个项目详情（home.vue:399-404） | 不要当作"审核列表"讲 |
| 文件搜索框 | toast `搜索功能开发中` | 全程不点搜索 |
| 筛选里的`文件格式`/`上传者` | 只改前端 chip，不参与请求 | 只演示`状态`与`所属阶段`筛选 |
| 文件`重新提交` | toast 开发中 | 只演示驳回，不点重提交 |
| 任务`进行中`筛选 | 前后端状态值不一致，必为空 | 只切`全部`/`待办`/`已完成` |
| 任务`负责人`下拉 | 只来源于已有任务的负责人 | 保证项目里已有带负责人任务，或演示时选已有人员 |
| 项目`重命名`/`成果管理` | toast 开发中 | 不点，或点了用旁白带过 |
| 项目`分享链接` | 小程序端只复制 token，无法打开访客页 | 只演示"分享码已复制"，不要承诺访客页 |
| 我的`编辑`/`操作记录`/`期末归档`/`存储与下载` | 均为 toast | 不点 |
| 我的两个开关 | 仅本地视觉状态 | 不演示，或不解释为"已保存设置" |
| 登录页协议链接 | 纯文本不可点 | 不点 |
| 图片以外的文件预览 | 依赖 `openDocument`，部分格式会提示不支持 | 优先用 PDF/Word 文件演示下载查看 |

> 另外：小程序端接口地址在代码里固定为 `http://116.62.81.113/api`（[api.js:13-18](file:///d:/zxc/work/git/roc-git/repository/roc-git/src/utils/api.js#L13-L18)）。录制前先确认该地址可达；如果在开发者工具里关闭域名校验，记得真机预览时改用合法域名，否则请求会失败。

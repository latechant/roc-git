# ROC-git · 课程小组文档协作管理平台

> 轻量化课程小组协作与文档版本管理系统，主打**文件审核、版本追溯、阶段化管理、过程留痕、多端文件导入**。

## 一、项目简介

### 1.1 项目定位
面向高校课程小组的协作管理平台，涵盖从**小组初始化 → 资料搜集 → 挂单审核 → 研讨迭代 → 版本留痕 → 阶段归档**全流程。

### 1.2 技术栈
| 层级 | 技术 |
|------|------|
| 架构 | B/S 前后端分离 |
| 前端 | Vue3 + TypeScript + Element Plus + Pinia + WebUploader |
| 后端 | SpringBoot (Java) + MyBatis-Plus + Redis |
| 数据 | MySQL 8.0 |
| 部署 | Tomcat / Jar 包一键启动 |

### 1.3 业务流程（15 个核心功能点）
1. 课程与团队初始化（权限分层）
2. 作业流程个性化配置（自定义阶段）
3. 小组任务分工管理（成员 + 职责 + 截止）
4. 团队资料搜集归集（本地 + 微信聊天双端）
5. 文件挂单审核准入流程（草稿 → 审核 → 入库）
6. 资料精细化管理（多维筛选、归档、清理）
7. 小组线上线下研讨支撑
8. 研讨成果落地更新
9. 阶段性作业成果产出
10. 作业成果审核入库
11. 文件版本迭代留痕（v1 → v2 → …，支持比对与回溯）
12. 分阶段成果沉淀归档
13. 全流程可视化追溯
14. 教师过程性评价考核
15. 期末整体归档留存

### 2.1 home.html — 首页

**顶部（3 栏布局）**

**数据概览区**：进行中 3 / 待审核 7 / 3天内截止 2

**临期任务预警区**
- 列表展示每个任务：阶段 + 标题 + 项目归属 + 倒计时
- 点击直接进入项目对应阶段

**当前项目区（横向滑动卡片，最多 3 个）**
- 横向滑动设计，带指示点，snap 滑动体验
- 第一张：主项目卡片（深色背景）——阶段标签、倒计时、总体进度、资料/待审核/版本三项数据、成员头像 + 角色

**挂单审核区（组长视角）**
- 待我处理列表：成员提交 → 一键通过 / 驳回

**归档项目区**

**底部 + 顶部**
- `+` 已移至顶部左上角；右上角：分享小程序码 + 退出

## 四、视觉规范

设计风格参考 iOS / 优秀移动端产品（如 Notion、Linear、Apple Music），遵循**极简、克制、呼吸感**的设计原则。

| 项目 | 值 |
|------|------|
| 主色 | `blue-600` `#2563EB`（专业、可靠） |
| 强调色 | `amber-500`（待处理） / `rose-500`（临期） / `emerald-500`（成功） |
| 中性背景 | `white` 卡片 / `#F8FAFC` 外框 |
| 卡片背景 | `white` + `slate-100` 边框 + 极淡阴影 |
| 圆角 | 卡片 16px，按钮 12px，标签 999px |
| 字体 | 系统 sans-serif，标题 font-semibold，正文 font-medium |
| 间距 | 大留白：节区 mt-8、区块内 mt-3、列表项 mt-2 |
| 配色原则 | 颜色只用于状态/分类，不滥用装饰色 |
| 图标库 | Lucide（细线、统一、易读） |

**核心设计语言**
- **单色为主**：90% 页面用 slate 中性色，10% 用语义色
- **无强分割**：用留白和颜色块分层，不用粗线条
- **状态用语义色**：amber=待办 / rose=临期 / emerald=成功 / blue=进行中
- **卡片轻量化**：阴影极淡，边框极浅，依赖白色与浅灰对比
- **按钮明确层级**：主操作用 blue 实心，次操作用 slate-100 浅底
